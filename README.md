# NeonTalk — Chat App

A real-time style chat application built with vanilla HTML, CSS, and JavaScript.

## Features

- 💬 Real-time messaging UI
- 🏠 Multiple chat rooms (General, Tech, Random, Jobs)
- 👤 Username + avatar setup
- 😊 Emoji picker
- 💾 Messages saved to localStorage
- 🌙 Dark neon theme
- 📱 Responsive design

## Tech Stack

- HTML5
- CSS3 (CSS Variables, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- localStorage for persistence

## Project Structure

```
chat-app/
├── index.html   # Login / username page
├── chat.html    # Main chat room
├── style.css    # All styles
├── login.js     # Login logic
├── chat.js      # Messaging logic
└── README.md    # This file
```

## How to Run

Open `index.html` in your browser — no install needed!
